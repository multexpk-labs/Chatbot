# Chatbot Evaluation

A chatbot needs measurable evaluation instead of relying only on subjective conversation quality.

## Test dimensions

- intent accuracy
- retrieval relevance
- response correctness
- groundedness
- instruction following
- tool-call correctness
- refusal behavior
- latency
- cost
- escalation accuracy

## Test set

Build a small versioned dataset of synthetic user requests with expected intent, required action, and acceptable response characteristics.

## Regression testing

Every production bug should become a reproducible test case when possible.
