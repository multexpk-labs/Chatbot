# Chatbot Security

## Core controls

- authentication and authorization
- tenant isolation
- input validation
- output validation
- rate limiting
- prompt-injection resistance
- tool permission boundaries
- secret management
- audit logging
- privacy and retention controls

## Tool security

Separate read-only tools from write tools. Use allowlists and explicit schemas. Add approval for irreversible operations.

## Logging

Do not log credentials, access tokens, private keys, or unnecessary personal data.

## Deployment

Use TLS, restricted service accounts, network controls, environment-based configuration, and monitored health endpoints.
