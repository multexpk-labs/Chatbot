# Chatbot Memory

Memory should solve a defined product problem rather than simply storing everything.

## Layers

- session context
- short-term conversation summary
- user preferences
- application state
- curated long-term knowledge

## Governance

Define what can be stored, retention duration, deletion behavior, access control, and whether the user can inspect or correct stored information.

## Public projects

Use synthetic memory examples. Never publish customer conversations, authentication tokens, personal identifiers, or private agent memory files.
